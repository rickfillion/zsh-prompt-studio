Install

      
    
        
  1. Install a Nerd Font and set it as your terminal font.
          
    brew install --cask font-jetbrains-mono-nerd-font
    2. 
        
  2. Press Copy .zsh, then save the clipboard:
          
    mkdir -p ~/.config/zsh && pbpaste > ~/.config/zsh/prompt.zsh
    3. 
        
  3. Load it from your zshrc, after any framework:
          
    echo 'source ~/.config/zsh/prompt.zsh' >> ~/.zshrc
    4. 
        
  4. Open a new tab, or run exec zsh.
    5. 
      

      
Using Oh My Zsh? Set ZSH_THEME="" so it doesn't fight this prompt. Using Powerlevel10k's instant prompt? Remove that block from your zshrc first.

    

  


  

    
Field notes
What popular prompts do, and what this studio borrowed.

    

      

        
zsh theme
Powerlevel10k

        
A configuration wizard (p10k configure) builds two-line “rainbow” prompts with a frame (╭─ ╰─) and a filler line that pushes right segments to the top row. Git status comes from a background daemon, so big repos stay fast. Also popularised the transient prompt.

        
Borrowed: frame, filler, right segments on the top line, transient prompt, state-colored git segment.

        github.com/romkatv/powerlevel10k
      

      

        
cross-shell, Rust
Starship

        
Configured in TOML, with a preset gallery: Pastel Powerline, Tokyo Night, Gruvbox Rainbow, Catppuccin Powerline. The pastel look pairs a rounded leading cap with sharp arrows between segments.

        
Borrowed: separate shapes for edge caps and separators, palette-driven recoloring.

        starship.rs/presets
      

      

        
minimal
Pure

        
Two lines, no backgrounds. Path, then branch with a dirty marker and ⇡⇣ arrows, then execution time when a command takes longer than 5 s. The ❯ character turns red when the last command failed.

        
Borrowed: Plain mode, exit-status prompt character, duration threshold.

        github.com/sindresorhus/pure
      

      

        
JSON themes
Oh My Posh

        
Segments come in powerline, plain and “diamond” styles: a diamond segment has its own leading and trailing glyphs, which makes floating capsules.

        
Borrowed: Capsules mode.

        ohmyposh.dev/docs
      

      

        
git internals
vcs_info vs. porcelain v2

        
zsh's built-in vcs_info needs hooks and extra git calls for untracked files and ahead/behind counts. git status --porcelain=v2 --branch returns branch, upstream distance and every changed file in one call.

        
Borrowed: the generated git segment parses porcelain v2 in pure zsh.

        git-scm.com/docs/git-status
      

      

        
the original
powerline-shell

        
The Python generator that made arrow segments common. It re-runs Python for every prompt, which is slower than doing the work in zsh.

        
Borrowed: segments hide themselves when they have nothing to say, so separators always line up.

        github.com/b-ryan/powerline-shell
